# 08 — Світові методики ефективного вивчення фінської: Hospodar YKI

> Стан на **21.10.2026**. Evidence-informed research shortlist, НЕ реліз застосунку. Машинозчитувані дані: [`research/learning-methods-v1.json`](../research/learning-methods-v1.json).

## Методологія рейтингу

**Оцінка 0–100 — наша експертна придатність для Hospodar YKI, не науковий effect size, не % успішності YKI.** Враховуємо докази (до 30), придатність для фінської/YKI (до 30), A2.2→B1 (до 20), простоту розробки (до 10), автономію та мотивацію (до 10). Суб'єктивні оцінки можуть коригуватися після тестування з учнями. Рейтинг НЕ сума effect sizes.

**Рівні доказів:** L2 meta-analysis > міжмовна педагогічна екстраполяція > локальні освітні рекомендації > гіпотези. OPH і CEFR задають компетенції, не підтверджують ефективність втручання. Переваги англійською не гарантують аналогічних для фінської, і жодне дослідження тут не оцінює шанс скласти саме YKI.

## Картки методик — докази, сценарій, метрика й обмеження

### 98/100 — Інтервальне активне пригадування (`spaced-retrieval`)

**Джерела:** [spaced](https://doi.org/10.1111/lang.12479), [retrieval](https://doi.org/10.1177/1529100612453266). **Доказовість:** HIGH_L2. **Черга:** P0.

**Суть:** Повторне самостійне відтворення з паузами краще за перечитування, особливо на відкладених тестах.

**Фінська вправа:** Haluaisin siirtää tapaamista — відтворити без зразка після 3 і 10 днів.

**Ідея для застосунку:** Адаптивний SRS для підтверджено проблемних chunks.

**Вимірюваний результат:** Recall у новому контексті через 7/14/30 днів.

**Межі доказу / ризик:** Немає єдиного найкращого розкладу інтервалів.

### 97/100 — Task-Based Language Teaching: вирішення життєвого завдання (`task-based`)

**Джерела:** [cefr](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions), [tblt](https://doi.org/10.1080/2331186X.2025.2560051), [kieliaudio](https://www.kielibuusti.fi/fi/opi-suomea/vinkkeja-kielenoppimiseen/kielivinkit-arkeen/vinkkeja-kuuntelemiseen-ja-puhumiseen). **Доказовість:** MODERATE_L2. **Черга:** P0.

**Суть:** Одиницею навчання є досягнута мета спілкування, не лише знання правила.

**Фінська вправа:** Soita huoltoyhtiöön: selitä ongelma, sovi aika, varmista jatko.

**Ідея для застосунку:** 20-хвилинні сценарії з ролями та змінними умовами.

**Вимірюваний результат:** Частка незалежно виконаних комунікативних задач.

**Межі доказу / ризик:** Не називати TBLT експериментально найкращим саме для YKI.

### 96/100 — Corrective feedback → самовиправлення → друга спроба (`prompted-self-repair`)

**Джерела:** [oralcf](https://eric.ed.gov/?id=EJ892626), [writingcf](https://doi.org/10.1016/j.learninstruc.2024.101961). **Доказовість:** HIGH_L2. **Черга:** P0.

**Суть:** Активне виправлення замість миттєвої готової моделі розвиває контроль форми.

**Фінська вправа:** Eilen olen mennyt → знайди помилку часу → Eilen menin.

**Ідея для застосунку:** 1–3 критичні помилки і guided repair після власної відповіді.

**Вимірюваний результат:** Частка самостійних виправлень і повторні помилки через тиждень.

**Межі доказу / ризик:** Не переривати екзаменаційну симуляцію.

### 95/100 — Зрозуміле поступово складніше аудіо й читання (`comprehensible-input`)

**Джерела:** [reading](https://doi.org/10.1002/tesq.157), [kieliaudio](https://www.kielibuusti.fi/fi/opi-suomea/vinkkeja-kielenoppimiseen/kielivinkit-arkeen/vinkkeja-kuuntelemiseen-ja-puhumiseen), [cefr](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions). **Доказовість:** MODERATE_INDIRECT. **Черга:** P0.

**Суть:** Регулярне посильне читання та слухання створюють ресурс для продуктивної мови.

**Фінська вправа:** Kuuntele uusi viesti; kerro mitä tapahtui ja miksi.

**Ідея для застосунку:** Нові тексти й аудіо A2.2→B1+, опори після спроби.

**Вимірюваний результат:** Відповіді на gist/details/inference на незнайомих матеріалах.

**Межі доказу / ризик:** Формула i+1 не є точним навчальним алгоритмом.

### 95/100 — Task Repetition із перенесенням у нову ситуацію (`task-repetition-transfer`)

**Джерела:** [speakingrepeat](https://doi.org/10.1016/j.system.2025.103868), [writingrepeat](https://doi.org/10.1016/j.jslw.2025.101255), [repetitionreview](https://doi.org/10.1016/j.rmal.2025.100292). **Доказовість:** HIGH_L2. **Черга:** P0.

**Суть:** Повторне формулювання тієї самої задачі покращує контроль мовлення; перенос треба перевіряти окремо.

**Фінська вправа:** Спочатку перенести час у лікаря; потім перенести зустріч із роботодавцем.

**Ідея для застосунку:** Task A → feedback → improved A → unseen B.

**Вимірюваний результат:** Якість непідказаної відповіді у зміненій ситуації.

**Межі доказу / ризик:** Не вважати завчений монолог доказом B1.

### 94/100 — Коротке пояснення граматики + практика у контексті (`explicit-context-grammar`)

**Джерела:** [explicit](https://doi.org/10.1111/flan.12726), [finnmorph](https://research.abo.fi/sv/activities/processing-of-inflectional-stem-changes-of-finnish-words-in-nativ-2/). **Доказовість:** HIGH_L2. **Черга:** P0.

**Суть:** Явна граматика корисна, якщо одразу потрібна для конкретного смислового вибору.

**Фінська вправа:** Menen kauppaan / olen kaupassa / tulen kaupasta.

**Ідея для застосунку:** Контраст форм, вибір значення, потім власний діалог.

**Вимірюваний результат:** Правильні відмінки у спонтанних нових репліках.

**Межі доказу / ризик:** Таблиці форм не замінюють реальне говоріння.

### 94/100 — Metacognitive Listening: передбачення, gist, details, рефлексія (`metacognitive-listening`)

**Джерела:** [metacog](https://doi.org/10.17960/ell.2023.29.1.006), [kieliaudio](https://www.kielibuusti.fi/fi/opi-suomea/vinkkeja-kielenoppimiseen/kielivinkit-arkeen/vinkkeja-kuuntelemiseen-ja-puhumiseen). **Доказовість:** MODERATE_TRANSFER_ENGLISH. **Черга:** P0.

**Суть:** Вчить усвідомлено перевіряти розуміння, а не просто перезапускати трек.

**Фінська вправа:** Mikä viestin aihe on? Mikä muuttui? Miksi?

**Ідея для застосунку:** Прогресивний плеєр: сліпа перша спроба, друге слухання, потім транскрипт.

**Вимірюваний результат:** Успіх із новими дикторами без субтитрів.

**Межі доказу / ризик:** Метааналіз переважно про навчання англійської.

### 94/100 — Незалежна діагностика 4 навичок і переносу (`unseen-diagnostics`)

**Джерела:** [cefr](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions), [selfassess](https://www.kielibuusti.fi/en/learn-finnish/language-learning-tips/assess-your-language-skills), [yki](https://www.oph.fi/en/education-and-qualifications/yki-test). **Доказовість:** HIGH_FRAMEWORK_INDIRECT. **Черга:** P0.

**Суть:** Розмежовує тренувальний прогрес і реальну здатність виконувати нові задачі.

**Фінська вправа:** Невідоме аудіо, новий лист і голосова ситуація без підказок.

**Ідея для застосунку:** Окремий тестовий банк і baseline кожні 2–4 тижні.

**Вимірюваний результат:** Окрема динаміка listening/reading/speaking/writing.

**Межі доказу / ризик:** CEFR — рамка навичок, а не доказ конкретного методу.

### 94/100 — Writing → feedback → rewrite → нове письмо (`writing-revision`)

**Джерела:** [writingcf](https://doi.org/10.1016/j.learninstruc.2024.101961), [writingrepeat](https://doi.org/10.1016/j.jslw.2025.101255), [kieliwriting](https://www.kielibuusti.fi/fi/opi-suomea/vinkkeja-kielenoppimiseen/kielivinkit-arkeen/vinkkeja-kirjoittamiseen). **Доказовість:** HIGH_L2_WRITING. **Черга:** P0.

**Суть:** Комбінований фідбек за змістом і мовною формою допомагає письмовій компетентності.

**Фінська вправа:** Напиши valitus, перевір вимоги, перепиши, потім інший лист.

**Ідея для застосунку:** Два критерії — зміст/структура та мова, і нова редакція.

**Вимірюваний результат:** Нове письмо з виконанням усіх умов та меншими повторними помилками.

**Межі доказу / ризик:** Не видавати AI-score за YKI grade 3.

### 93/100 — Kirjakieli ↔ puhekieli, впізнавання регістрів (`kirja-puhe`)

**Джерела:** [kieliaudio](https://www.kielibuusti.fi/fi/opi-suomea/vinkkeja-kielenoppimiseen/kielivinkit-arkeen/vinkkeja-kuuntelemiseen-ja-puhumiseen), [s2bank](https://www.kielibuusti.fi/fi/suomenopettajat/s2-opetusmateriaalipankki). **Доказовість:** FINNISH_SPECIFIC_APPLIED. **Черга:** P0.

**Суть:** Реальне фінське мовлення містить скорочення, письмовий стандарт потрібен для текстів.

**Фінська вправа:** Minä olen ↔ mä oon; sinä olet ↔ sä oot.

**Ідея для застосунку:** Парні аудіо від живих мовців з тегами регістру.

**Вимірюваний результат:** Розуміння живого мовлення й доречність регістру.

**Межі доказу / ризик:** Не узагальнювати один діалект як єдину норму.

### 92/100 — Функціональні мовні chunks і колокації (`chunk-learning`)

**Джерела:** [spaced](https://doi.org/10.1111/lang.12479), [kieliaudio](https://www.kielibuusti.fi/fi/opi-suomea/vinkkeja-kielenoppimiseen/kielivinkit-arkeen/vinkkeja-kuuntelemiseen-ja-puhumiseen), [cefr](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions). **Доказовість:** MODERATE_APPLIED. **Черга:** P0.

**Суть:** Найважливіше — активно вживати корисні конструкції, а не впізнавати словник.

**Фінська вправа:** Voisitteko auttaa? Olen kiinnostunut tästä.

**Ідея для застосунку:** Chunk cards із керуванням, прикладом і transfer.

**Вимірюваний результат:** Самостійна частота доречних chunk у нових задачах.

**Межі доказу / ризик:** Додавати тільки реально проблемні конструкції.

### 92/100 — High-Variability Phonetic Training: багато дикторів (`high-variability-phonetics`)

**Джерела:** [hvpt](https://doi.org/10.1017/S0272263125100879), [hvptprod](https://doi.org/10.1017/S0142716424000195). **Доказовість:** HIGH_L2_PERCEPTION. **Черга:** P0.

**Суть:** Різні голоси тренують сприймання фонем, з обмеженим автоматичним переносом на вимову.

**Фінська вправа:** tuli / tuuli, muta / mutta, kuka / kukka.

**Ідея для застосунку:** Різні голоси, контрасти, random trials і feedback.

**Вимірюваний результат:** Точність на нових дикторах та невивчених словах.

**Межі доказу / ризик:** Перцептивний прогрес ≠ гарантована правильна вимова.

### 91/100 — Extensive Reading на посильному рівні (`extensive-reading`)

**Джерела:** [reading](https://doi.org/10.1002/tesq.157). **Доказовість:** HIGH_L2_READING. **Черга:** P0.

**Суть:** Регулярне об'ємне читання покращує навичку читання та мовний досвід.

**Фінська вправа:** Lue selkouutinen; kerro tärkein ajatus.

**Ідея для застосунку:** Градуйована бібліотека з reading-for-meaning.

**Вимірюваний результат:** Невідомі reading inference питання.

**Межі доказу / ризик:** Саме по собі не замінює розмову.

### 91/100 — Контрастивна фінська морфологія: KPT, rektio, sijamuodot (`finnish-morph-contrast`)

**Джерела:** [explicit](https://doi.org/10.1111/flan.12726), [finnmorph](https://research.abo.fi/sv/activities/processing-of-inflectional-stem-changes-of-finnish-words-in-nativ-2/). **Доказовість:** HIGH_INSTRUCTION_FINNISH_TRANSFER. **Черга:** P0.

**Суть:** Треба навчитися вибирати правильну форму за змістом у словосполученні.

**Фінська вправа:** kaupunki → kaupungissa → kaupunkiin; odotan bussia.

**Ідея для застосунку:** Інтерактивні контрасти й реєстр системних помилок.

**Вимірюваний результат:** Точність у нових ситуативних реченнях.

**Межі доказу / ризик:** Лінгвістична QA обов'язкова для винятків.

### 91/100 — Мікромісії в реальному фінському середовищі (`real-world-interaction`)

**Джерела:** [kieliaudio](https://www.kielibuusti.fi/fi/opi-suomea/vinkkeja-kielenoppimiseen/kielivinkit-arkeen/vinkkeja-kuuntelemiseen-ja-puhumiseen), [kielitips](https://www.kielibuusti.fi/fi/opi-suomea/vinkkeja-kielenoppimiseen). **Доказовість:** MODERATE_APPLIED. **Черга:** P0.

**Суть:** Справжні розмови створюють непередбачуваність і соціальні наслідки.

**Фінська вправа:** Попроси фінською уточнити час автобусу або зустрічі.

**Ідея для застосунку:** Опціональна місія поза застосунком із приватним самозвітом.

**Вимірюваний результат:** Різноманітність завершених реальних мовних дій.

**Межі доказу / ризик:** Не записувати третіх осіб без згоди.

### 90/100 — Субтитри і транскрипти з поступовим приховуванням (`caption-fading`)

**Джерела:** [caption](https://doi.org/10.1111/lang.12697), [gloss](https://doi.org/10.1016/j.actpsy.2024.104341). **Доказовість:** HIGH_L2_LEXIS. **Черга:** P0.

**Суть:** Текст допомагає осмислити нову лексику, але розуміння без нього окреме.

**Фінська вправа:** Дивись/слухай без тексту → покажи транскрипт → новий запис без нього.

**Ідея для застосунку:** Стан hidden-until-attempt у плеєрі.

**Вимірюваний результат:** Listening score на першій спробі без transcript.

**Межі доказу / ризик:** Recognition із субтитрами не дорівнює самостійному слуханню.

## Рекомендована інтегрована місія (20 хв — адаптивна гіпотеза)

1. **3 хв**: тільки підтверджено проблемні chunks — active recall без підказок.
2. **5 хв**: нове автентичне B1-подібне аудіо або текст; спочатку gist/details, потім за потреби транскрипт.
3. **7 хв**: життєве завдання у speaking або writing — реальний результат, а не таблиця.
4. **3 хв**: 1–3 найважливіші помилки → самовиправлення → ще одна спроба.
5. **2 хв**: нова схожа ситуація без моделі (transfer).
6. **Раз на тиждень**: новий довший людський запис, одне повне письмо з revision, інша жива розмова і unseen mini-test.

*20 хв не є доведеним ідеальним навчальним часом, режим налаштовується індивідуально.*

## Особливості саме фінської

- **KPT і відмінки:** спочатку питання `missä/mistä/mihin`, контраст значень і наочний контекст; потім власне речення, rektio і transfer.
- **kirjakieli та puhekieli:** розділяти формальний текст і спонтанне мовлення, показувати два регістри; не змішувати регіональні діалекти з нормою.
- **Довгі звуки:** живі різні голоси для `tuli/tuuli`, `kuka/kukka`; TTS потребує ручної фонетичної перевірки.
- **Чотири навички:** не можна робити висновок B1 зі словникових карток або успіху в знайомих quiz.
- **Перед релізом:** S2-викладач перевіряє ключі й фінську природність; звуковий режим має бути доступним і вимикатися.

## Контраргументи для продуктових рішень

- **Spaced practice:** у L2 метааналізі підтверджений відкладений ефект, але рівні й розширювані інтервали статистично подібні: [spaced](https://doi.org/10.1111/lang.12479).
- **HVPT:** 79 робіт підтримують покращення сприймання фонем, але генералізація на вимову слабкіша: [hvpt](https://doi.org/10.1017/S0272263125100879), [hvptprod](https://doi.org/10.1017/S0142716424000195).
- **Письмо та AI:** комбінований feedback корисний; новий огляд algorithm-based feedback не доводить стійкого покращення surface accuracy і свідчить про обмежений transfer: [writingcf](https://doi.org/10.1016/j.learninstruc.2024.101961), [aifeedback](https://www.sciencedirect.com/science/article/pii/S107529352600022X).
- **Гейміфікація:** загальноосвітній метааналіз мотивації g=0.257; мовні ігри краще підтверджені для словника/вимови, ніж для продуктивних навичок: [games](https://doi.org/10.1007/s11423-023-10337-7), [mobilegames](https://doi.org/10.1080/09588221.2025.2528786).
- **Рольові ігри та AI:** AI-співрозмовник перспективний, але мовні помилки, приватність, якість оцінки й ризик залежності від підказок потрібно тестувати: [genai](https://doi.org/10.1111/jcal.70060).
- **Субтитри:** покращення впізнавання слів не є автоматично покращенням аудіювання без тексту: [caption](https://doi.org/10.1111/lang.12697), [gloss](https://doi.org/10.1016/j.actpsy.2024.104341).
- **Фінські рекомендації:** Kielibuusti рекомендує реальне використання фінської в роботі, спілкування й самостійну практику, але ці поради не замінюють контрольовані експерименти: [kieliaudio](https://www.kielibuusti.fi/fi/opi-suomea/vinkkeja-kielenoppimiseen/kielivinkit-arkeen/vinkkeja-kuuntelemiseen-ja-puhumiseen).

- **Початкова спроба має бути самостійною**; підказки та моделі відкривати тільки після attempt, крім явно scaffolded training.
- Не дозволяти автоматичну оцінку вимови на основі однієї розшифровки ASR.
- Аудіо каталогізувати як synthetic/human, duration, verified transcript, register, narrator count, rights, QA status.
- Не зберігати приватні відповіді користувачів у публічному репозиторії.
- Метрики: unseen 7/14-day recall, незалежна comprehension accuracy, task completion, repair success, transfer to new tasks; не streak.
- Спершу валідований простий навчальний цикл, потім AI/маскот/ефекти. Екзаменаційний digital UI 2027 — тільки за перевіреними даними OPH.
