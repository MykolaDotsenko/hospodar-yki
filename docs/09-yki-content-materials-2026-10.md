## Основна стратегія

1. **Дані й словник:** ліцензований частотний ресурс Radice/Kotus → добір B1 корисних лем → власний український переклад/керування/фраза → S2 редактура.
2. **Речення:** власні контекстні речення та перевірені за кожним реченням ліцензовані Tatoeba (автор, ID, CC BY 2.0 FR або окремі CC0), після фільтрації на якість; не імпортувати неоцінений величезний корпус просто заради кількості.
3. **Розмовна мова:** Kielibuusti Puhutsä suomee? / місцеві відео лише як ПОСИЛАННЯ. Для застосунку створюємо оригінальні варіанти діалогів, записуємо легально ліцензованими дикторами.
4. **Тексти/аудіювання:** офіційні демонстрації OPH/JYU та B1-вправи Yle залишаються на зовнішніх сторінках; у продукті — наші нові тексти з ключами, аудіо, перевірка підказок після спроби.
5. **Справжні документи:** матеріали Kela, муніципалітетів і Selkouutiset використовувати для читання через оригінальні сторінки; не видавати їхні зміни, тарифи та терміни за сталі приклади.

## Найвища педагогічна цінність (наступні етапи)

**P0 — незалежне говоріння:** відтворення 20–40 частотних комунікативних chunks, 1–2 хв на знайомі ситуації, рольові дзвінки, ввічливі прохання, аргументація. Слова оцінювати тільки на самостійному активному вживанні.

**P0 — аудіювання:** нові 2–3-хвилинні B1/B1+ монологи/діалоги із різними живими дикторами, точними транскриптами, метаданими speaker/register/speed, питання на gist/details/inference. Тренувальні slow/subtitles після першої спроби.

**P0 — читання:** системні жанри (оголошення, повідомлення житлового товариства, обслуговування, лист, інструкція, думка). Кожен текст — evidence-based single choice + open answer + реальний writing/speaking transfer. Наш новий 9-текстовий пакет є коротким стартом, **не** заміною повним екзаменаційним читальним банком.

**P0 — письмо:** повідомлення другу, звернення до установи, скарга, аргументована думка; рубрика task fulfilment окремо від граматики; чернетка → self-repair → незнайома тема.

**P1 — частотність:** у Radice news frequency високі новинні леми, яких рідко вживають у побутовій B1-розмові. Комбінувати частоту, комунікативну користь, відомість конкретному учню, складність форм. Ніколи не зараховувати імпортовані 10k лем до засвоєних чи невідомих.

## Жорсткі обмеження прав і якості

- Tatoeba: текст CC BY 2.0 FR **з атрибуцією конкретного автора**, де можливо — CC0; текст і звук можуть мати різні права. Вимагати human proofread та видаляти помилкові/застарілі речення: https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus
- Korp API — механізм пошуку, не загальна ліцензія на тексти. Перевіряти кожну collection license до запису прикладів.
- FinnWordNet: CC BY 3.0 для фінських перекладів + окрема ліцензія Princeton WordNet для похідної структури.
- Omorfi/GiellaLT GPLv3: окремий legal/architecture review до вбудовування в закритий клієнт; не переносити у клієнт автоматично.
- Yle/Kielibuusti/Kielitoimiston sanakirja/Kela: те, що можна безкоштовно читати онлайн, не означає, що дозволено передруковувати тексти й аудіо у відкритий GitHub чи додаток.
- Нинішні авторські завдання — **draft** до редактури кваліфікованого викладача фінської. Жодна авто-перевірка не встановлює природність чи рівень B1.
- Джерела з `verification` — сторінки чи репозиторії, не твердження, що ми повністю вичитали всі сторінки/книги/платні курси.

## Схема навчальної картки майбутнього застосунку

Зв'язки: `lemma → sense → chunk → contextual_sentence → scenario → reading/audio → question → own_answer → error → next_review`. Метадані: `topic`, `level_hint`, `register`, `grammar`, `source`, `license`, `author`, `original_id`, `teacher_review`, `assessment_eligibility`. Приватні відповіді, аудіозаписи учнів та SRS-профіль **поза публічним репозиторієм**.

## Definition of Done перед запуском

1. Контент технічно валідний (унікальні ID, цілісні права/атрибуції, правильні ключі, evidence у тексті).
2. Учитель S2 перевірив природність фінської, контекст, рівень і ключі; для записів прослухано вимову.
3. Для кожної навички є **незнайомі** контрольні задачі, не перемішані з навчальними.
4. Відстежується 7–14-денний результат на новому контексті, а не кількість кліків.
5. Інтерфейс читання/слухання доступний і без несподіваних звуків; audio transcript/answer not revealed early.
6. Правова перевірка поширення джерела завершена, перш ніж копіювати повний текст/запис.
