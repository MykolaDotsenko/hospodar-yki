# Hospodar YKI — структура репозиторію

**Чинний стан:** фізичні файли у власних тематичних папках. Окремих каталогів-реєстрів немає. Кожна папка містить реальні матеріали; README пояснює призначення, а не дублює файли.

```text
hospodar-yki/
├── app/                         # Поточний працюючий Web MVP
├── assets/
│   ├── images/brand/            # Справжні SVG логотипи
│   ├── audio/{human,long,open,segments}/  # OGG/MP3, субтитри, записи
│   └── video/open/              # Ліцензовані локальні WebM
├── learning/
│   ├── exercises/b1/            # Теми, діалоги, граматика, діагностика,
│   │                             # практичний іспит, аудіоуроки, high-yield
│   ├── exercises/video/         # Вправи для реального відео
│   ├── plans/                   # Навчальні плани, 4 тижні слухання
│   └── CONTRIBUTING.md          # Як додавати навчальний контент
├── knowledge/
│   ├── dictionaries/b1/         # Частотні слова, chunks, rektio

```

## Простий принцип

- Аудіо — у `assets/audio/`; відео-файли — у `assets/video/`; зображення — у `assets/images/`. Файли не дублюються у папках вправ.
- Посилання на YouTube — у `sources/youtube/`, а **не** серед локальних файлів відео. Записи YouTube не завантажуються в репозиторій чи Android PAD.
- Навчальні плани — у `learning/plans/`; **не** серед аудіобінарників. Зовнішні аудіоджерела — у `sources/audio/` (не в `assets/audio/`).
- Навчальні JSON — у `learning/exercises/`. Словники — у `knowledge/dictionaries/`; навчальні відомості про книги та джерела — у `knowledge/sources/`.
- Дослідження живуть за **темою**, а не в одному спільному архіві. Впроваджена поведінка відрізняється від запропонованої: React/Phaser/PAD — майбутні рішення.
- Право на публічне переглядання не є правом на передрук чи перепоширення. Ліцензії в existing файлах зберігаються, незнайомі права потребують перевірки.
- ID вправ і оригінали медіа не змінені; змінюються лише файлові шляхи, включно з їхніми споживачами. Файли не перейменовуються без потреби.
- Додаткові JSON реєстри `catalog/` видалено: достатньо **самої файлової структури** та локальних README.

## Перевірка після перенесення

```sh
python3 scripts/validate_folder_layout.py
node --test app/tests/*.test.mjs
node --test packages/contracts/tests/*.test.mjs
```

Окремі валідатори кожної навчальної категорії й браузерні тести запускаються в CI. Якщо десь залишився старий шлях, треба виправити *споживача*, а не повертати дублікати файлів або обходити помилку.
