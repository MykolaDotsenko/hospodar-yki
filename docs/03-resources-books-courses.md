### Пріоритет №1 — YKIä kohti

- Дев'ять тематичних розділів; в кожному присутні **читання, письмо, аудіювання, говоріння**.
- Повторювана дидактична структура **Lämmittele → Harjoittele → Testaa**. Перший етап — актуалізація знань, другий — практика з опорами, третій — без них.
- Видавництво має **зразки** та опис принципів; **не можна стверджувати, що весь платний підручник прочитаний**, якщо доступні лише фрагменти.
- Аудіо для власника книги доступне через **Nova** після використання ISBN друкованої книги. Окрема платна MP3-версія (~94,10 €) **не обов'язкова**, поки можна використовувати Nova.
- PDF із розв'язками/транскриптами видавець продає окремо (~12,50 €); купувати лише за потреби.

**Джерело:** [Finn Lectura, product family, snippets, Nova](https://finnlectura.fi/oppimateriaalit/suomi-toisena-kielena/ykia-kohti/).

## Безкоштовне ядро — порядок пріоритету

1. [Jyväskylän yliopisto / CALS — YKI demo](https://ykitesti.solki.jyu.fi/tutustu-testiin/testifin/) — **офіційні демонстраційні типи завдань**, головний еталон за структурою.
2. [Yle — YKItreenit](https://yle.fi/a/20-146803) — аудіо, читання, фрази і вправи.
3. [Yle B1 YKI 2024](https://yle.fi/a/74-20082612) — додаткова практика тематичного читання/слухання.
4. [Gimara](https://gimara.fi/) — speaking із паузами для відповіді.
5. [Helsingin aikuisopisto — YKI-harjoitukset](https://helao.fi/ohjeita-ja-harjoituksia-ykiin/).
6. [Uusi kielemme](https://uusikielemme.fi/) — довідник граматики, не офіційний екзаменаційний ресурс.
7. [OPH — Before the YKI test](https://www.oph.fi/en/education-and-qualifications/yki-test) — зміст і правила з перших рук.

## Що купувати (ROI)

- **Мінімум:** YKIä kohti (41,80 €) + відкриті Yle/OPH/Gimara + тренування з перевіркою.
- **Оптимум:** додати Suomen mestari 3 Uudistettu **лише якщо стартова діагностика виявить системні граматичні прогалини**.
- **Якщо письмо слабке:** додати Kynä käteen! або курс із перевіркою індивідуальних текстів.
- **До іспиту:** спеціалізований YKI-prep у березні корисний, якщо є живий коригувальний feedback і mock exams; не купувати три паралельні курси без необхідності.
- Орієнтир: сумарна вартість **YKIä kohti + Kynä käteen! = 61,70 €** за цінами видавництв зі зрізу. Раніше обговорювана пара YKIä kohti + Suomen mestari 3 ~92,30 € — **лише історичний орієнтир**, не гарантія ціни.

- Цінові пропозиції та наявність перевіряти **перед покупкою**.
