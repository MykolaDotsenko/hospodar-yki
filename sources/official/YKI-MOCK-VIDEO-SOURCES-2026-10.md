## II. Найкращі джерела для власної максимально точної імітації — SOLKI/Jyväskylä (не YouTube)

1. **[Офіційний індекс демозавдань по всіх 4 навичках](https://ykitesti.solki.jyu.fi/en/tutustu-testiin/testifin/)**.
2. **[Puhuminen — keskitaso, аудіо та текст завдань](https://ykitesti.solki.jyu.fi/tutustu-testiin/testifin/keskitaso-puhuminen/)**: `kertominen` (приклад: 1 хв підготовки, 1.5 хв усної відповіді), `keskustelu` (клієнт/продавець, замовлення зали, продаж), `tilanteita` (питання про транспорт, аптека, запізнення, скарга на ремонт), `mielipide` (приклад: 2 хв для висловлення аргументованої думки). На сторінці є посилання на **оригінальні MP3 демозавдань**. **Таймінги — лише приклади історичної демонстрації, не підтверджені правила digital-2027.**
3. **[Puheen ymmärtäminen — keskitaso](https://ykitesti.solki.jyu.fi/tutustu-testiin/testifin/keskitaso-puheen-ymmartaminen/)**: MP3 й повні структури `monivalinta / oikein–väärin / avoimet kysymykset`, приклади підготовки й повторного прослуховування. На сторінці також є застарілі *paper answer sheet* інструкції; **їх НЕ переносити як цифрову поведінку**.
4. [Tekstin ymmärtäminen — keskitaso](https://ykitesti.solki.jyu.fi/tutustu-testiin/testifin/keskitaso-tekstin-ymmartaminen/) — окремий розділ індексу; цільова сторінка іноді повертає 502, тому окремі завдання не пройшли детальний перегляд у цьому аудиті.
5. [Kirjoittaminen — keskitaso](https://ykitesti.solki.jyu.fi/tutustu-testiin/testifin/keskitaso-kirjoittaminen/) — окремий розділ індексу; цільова сторінка іноді повертає timeout, тому окремі завдання не пройшли детальний перегляд.

**Офіційний контекст:** [OPH: Ennen YKI-testiä](https://www.oph.fi/fi/koulutus-ja-tutkinnot/ennen-yki-testia) прямо пояснює, що це **приклади для ознайомлення, не реальні офіційні екзаменаційні завдання**. [OPH: тестові дати](https://www.oph.fi/fi/koulutus-ja-tutkinnot/sopivan-yki-testin-valinta-ja-testipaivat) підтверджує **цифровий фінський YKI навесні 2027**, отже старі відео з паперовими інструкціями або описами `kielistudio` НЕ можуть вважатися інтерфейсною копією нового тесту.

## III. Відео-інструкції, а не timed mock

- [Gimara Oy: Puhumisen osakoe (YKI Intermediate)](https://www.youtube.com/watch?v=asoKfPYu6pY) — авторитетне пояснення чотирьох типів говоріння від викладача Gimara/Arffman (відео 2020); **це не імітація** та пояснює старі умови.
- [Gimara/YKI learning playlist](https://www.youtube.com/playlist?list=PLUCgSYHrzBhk8Lrz1_a1i4md2YXyeG7Kb) — підбірка уроків і практики; не називати всі елементи `full mock` без індивідуального QA.
- [Daily Finnish: YKI dialogues / mock story](https://www.youtube.com/watch?v=qb-NFR74m8Q) — 11 історій про підготовку і пробний тест, але **A1–A2** і фіктивні персонажі. Це матеріал для базового розуміння мови, **не YKI keskitaso mock**.
- [Daily Finnish: YKI Test Preparation – Easy Conversation](https://www.youtube.com/watch?v=hiucp_IWbaM) — аналогічно **A1–A2**. Наявність слова `mock` в описі **не робить відео повною симуляцією YKI**.

## IV. Технічний контракт Hospodar YKI — не змішувати навчальні джерела і валідацію цифрового тесту

| Contract | Acceptance |
|---|---|
| `MOCK-VID-01` | кожен YouTube video має `mock_type`: `timed_subtest`, `task_demo`, `format_explainer`, `story_about_exam`, `not_mock`; `full_digital_2027_exam_mock` залишається **false** доки немає доказу |
| `MOCK-VID-02` | якщо у відео є зразок відповіді, в нашому каталозі збережено `model_answers_start_seconds`; `mock` спроба завершується ДО зразка |
| `MOCK-VID-03` | `YKI official organizer demo` означає автентичне джерело прикладів, а НЕ офіційні реальні екзаменаційні питання або дозвіл копіювати |
| `MOCK-VID-04` | для нової цифрової симуляції використовувати окремий `versioned evidence ledger` (типи задач, timers, audio playback, recording, ability to edit, UX, scoring). Незаповнені поля = fidelity `unknown` |
| `MOCK-VID-05` | у LEARN можна вбудувати YouTube через офіційний embed за дотримання умов, а EXAM використовує **лише оригінальний/licensed і незалежний тестовий банк** |
| `MOCK-VID-06` | `teacher_review/publisher_embed_permission/rights` залишаються `pending`, жодної неправдивої обіцянки `YKI 100% fidelity` |
| `MOCK-VID-07` | для чесного speaking mock: аудіопідказка → підготовка → запис відповіді за згодою → pause/finish → self-repair **лише після завершення** |
| `MOCK-VID-08` | статус `attempt_exposure`/підглядання модельних відповідей впливає на `seen`/ `held_out`. Переглянуте відео не є новою непідказаною перевіркою |

### Наступний крок для реалізації

**Найрозумніший vertical slice:** самостійно відтворити YKI `keskitaso puhuminen` із авторськими задачами нашого продукту: `kertominen → keskustelu → tilanteita → mielipide`, із явними practice-таймерами, мікрофоном, аудіовказівками, контентними QA та збереженням прогресу. Як демо використовувати `htrQhR-HGM4`, для дизайну завдань — офіційні приклади SOLKI. Не повідомляти користувачу, що це офіційний цифровий тест-2027; такий статус неможливий без нових OPH-даних.
