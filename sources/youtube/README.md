# YouTube — curated external links, never downloaded audiovisual content

**Canonical working catalog:** [sources/youtube/youtube-catalog.json](youtube-catalog.json). Existing import/validation scripts and summaries depend on this stable path; this folder is the **semantic discovery owner**, not a duplicate JSON copy.

Related research: [sources/youtube/YOUTUBE-LEARNING-CATALOG.md](YOUTUBE-LEARNING-CATALOG.md), [round 2](YOUTUBE-HIGH-VALUE-ROUND2-2026-10.md), [round 3](YOUTUBE-AND-PUBLISHERS-HIGH-VALUE-ROUND3-2026-10.md), [round 4](YOUTUBE-B1PLUS-HIGH-VALUE-ROUND4-2026-10.md), [round 5](YOUTUBE-AND-YLE-B1-HIGH-VALUE-ROUND5-2026-10.md).

**Allowed records:** stable YouTube video ID, `https://www.youtube.com/watch?v=...`, title/creator as attributed, episode/chapter offsets, topics, four skills, tentative CEFR, cited source of metadata, review/availability status. Do not assert a tested transcript when not actually reviewed.

**Hard licensing boundary:** `link_only`. Do not import/cache/down­load/split YouTube audiovisual streams (including soundtrack), create unofficial offline copies, or imply embedding permitted. Refer to [YouTube Developer Policies](https://developers.google.com/youtube/terms/developer-policies) and [guidance](https://developers.google.com/youtube/terms/developer-policies-guide). If a creator independently offers a licensed master via a separate source, register that as a **different asset with its own explicit rights evidence**, not a backdoor YouTube download.
