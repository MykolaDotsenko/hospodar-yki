# Research — task-scoped agent instructions

Read [root agent policy](../AGENTS.md), [research program](RESEARCH-PROGRAM.md), [method owner](pedagogy/README.md), [UX protocol](ux/learning-impact-evaluation-protocol.md), and [handoff rules](../docs/guides/EVIDENCE-TO-UX.md) **only as relevant**.

- Preserve one physical topic owner: pedagogy, UX, design, gameplay, user-cases, YKI or architecture. Do not create second catalog/registry or copy sources to several places.
- Each new claim needs citation (prefer DOI/official original), population/comparator/measure/limitations, contradictory/null evidence and explicit applicability to adult Finnish A2–B1. No source supports an invented product uplift.
- Separate research hypothesis, approved spec, implementation and actual measured benefit; scores out of 100 for method fit are **not** empirical effect sizes or YKI pass probabilities.
- Reuse existing source/method IDs; the historical 67 methods and 69 sources are a *minimum*, not a fixed denominator. New method requires corresponding effectiveness entry, Markdown card and source/priority metadata. Run \`python3 scripts/validate_learning_methods.py\` and \`python3 scripts/validate_learning_books_bridge.py\`.
- For sound, focus, animation, rewards and AI, use controllable accessibility fallbacks, no auto-play distractions and delayed **unseen** Finnish transfer studies before effectiveness claims.
- Run Markdown/folder validation and the PR quality gates. Respect redistribution rights; do not place human voice data or private learner records in public Git.
