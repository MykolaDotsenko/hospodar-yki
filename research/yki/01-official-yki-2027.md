# 01 — YKI suomi keskitaso: офіційні правила на 2027 рік

> **Тип:** OFFICIAL (OPH, Migri). **Перевірено:** 2026-10-21. Перед реєстрацією повторно перевірити вебсторінки, особливо дату, місця і ціну.

## Навіщо та який рівень

- YKI = Yleiset kielitutkinnot, національний іспит для дорослих, а не курс.
- Шкала: perustaso 1=A1 / 2=A2; **keskitaso 3=B1 / 4=B2**; ylin taso 5=C1 / 6=C2.
- Для мовної вимоги громадянства зазвичай підходить **YKI 3+**, але також необхідні **інші окремі** умови громадянства.
- Оцінки в сертифікаті **окремі** за чотирма модулями, загального «бала зі 100» немає.
- Для громадянства Migri приймає будь-яку з **трьох** пар оцінок 3 або 4:
  1. **puhuminen + kirjoittaminen** (говоріння + письмо);
  2. **puheen ymmärtäminen + kirjoittaminen** (аудіювання + письмо);
  3. **tekstin ymmärtäminen + puhuminen** (читання + говоріння).
- Допускається **два різні сертифікати**, якщо їхні результати разом утворюють дозволену пару. Результат за іншою парою не слід помилково трактувати як достатній.
- У контексті ПМП можуть діяти інші вимоги/підстави; не переносити правила громадянства автоматично.

**Першоджерела:** [OPH — рівні, структура, календар](https://www.oph.fi/en/education-and-qualifications/selecting-right-yki-test-test-days), [Migri — YKI для громадянства](https://migri.fi/en/national-certificate-of-language-proficiency-yki-), [Migri — мовна вимога](https://migri.fi/en/language-skills).

## Структура і оцінювання

| Модуль | Фінська назва | Перевіряється |
|---|---|---|
| Listening | Puheen ymmärtäminen | Головна і конкретна інформація, сенс сказаного |
| Speaking | Puhuminen | Реакція, самостійне повідомлення, думка, взаємодія |
| Reading | Tekstin ymmärtäminen | Зміст, цілі, факти й аргументи тексту |
| Writing | Kirjoittaminen | Зрозумілий текст відповідно до комунікативного завдання |

У тесті *keskitaso* успішні оцінки — **3 або 4** для відповідного модуля. Результати не переводяться у єдиний офіційний відсоток правильних відповідей. Мовні компетенції оцінюють навчені екзаменатори за критеріями YKI.

**Першоджерела:** [OPH — після тесту / assessment criteria](https://www.oph.fi/en/education-and-qualifications/after-yki-test).

## Офіційний календар весни 2027 (фінська)

| Тест | Реєстрація | Рівні / модулі |
|---|---|---|
| **16.01.2027** | 04–07.01.2027 | keskitaso, ylin; всі |
| **13.02.2027** | 18–28.01.2027 | perustaso, keskitaso; всі |
| **10.03.2027** | 08–22.02.2027 | keskitaso; **говоріння + читання** |
| **10.04.2027** | **08–25.03.2027** | keskitaso, ylin; **всі 4** |
| 24.04.2027 | 22.03–08.04.2027 | perustaso; всі — **не підходить для B1** |
| **12.05.2027** | 12–26.04.2027 | keskitaso; **письмо + аудіювання** |
| 22.05.2027 | 20.04–06.05.2027 | ylin; всі — **не keskitaso** |
| **02.06.2027** | 03–17.05.2027 | keskitaso; **говоріння + читання** |

Реєстрація починається **о 10:00 за фінським часом**. Місця на фінський keskitaso швидко закінчуються; сама наявність дати не гарантує місця у конкретному місті. Канонічний графік: [OPH](https://www.oph.fi/en/education-and-qualifications/selecting-right-yki-test-test-days). Реєстрація: https://yki.opintopolku.fi/.

**Пріоритет:** 10.04.2027 повний тест. Травень/червень — за потреби окремих модулів; вони не замінюють автоматично потрібні для громадянства комбінації.

## Цифровізація 2027

- **Усі тести з фінської навесні 2027 — цифрові** (офіційний календар OPH).
- Комп'ютер у тестовому центрі; **власний ноутбук не потрібен**, це **не дистанційний домашній** іспит.
- Офіційне пілотування цифрового формату у листопаді 2026; за інформацією OPH вправи за суттю подібні до паперових.
- **Не можна** наперед стверджувати точний вигляд UI, розміщення кнопок, спосіб відліку часу/запису, дозволеність чернеток тощо, якщо OPH цього не описало.
- Демонстраційні завдання Jyväskylä корисні для **типів діяльності**, але історичні вказівки про паперові бланки не переносяться без перевірки на новий іспит.

**Першоджерело:** [OPH — digital YKI pilot, 18.09.2026](https://www.oph.fi/en/news/2026/digital-yki-tests-will-be-piloted-november-2026).

## Ціни (опубліковані на 2026-10-21; TO RECHECK)

- Повний keskitaso: **190 €**; базовий 165 €, вищий 216 €.
- Окремі модулі: puheen ymmärtäminen 43 €; puhuminen 84 €; tekstin ymmärtäminen 43 €; kirjoittaminen 70 €.
- Пари за офіційними тарифами: говоріння+читання = **127 €**; письмо+аудіювання = **113 €** (арифметична сума тарифів модулів).
- Оплата онлайн за отриманим email-посиланням, типовий термін — **1–3 дні**; непроведена оплата означає відсутність підтвердженої участі.
- Правила повернення суворі. З 01.01.2026 OPH вимагає одночасно хворобу заявника з доказом, скасування не пізніше **08:00 дня тесту** і заяву протягом **2 тижнів** після тесту.
- Після оплати не планувати зміну дати/місця/рівня як гарантовану можливість.

**Першоджерело:** [OPH — Registering](https://www.oph.fi/en/education-and-qualifications/registering-yki-test).

## День тесту і результати

- Тест у призначеному центрі, необхідний **чинний документ**, що OPH приймає для ідентифікації; перевірити конкретний перелік на сторінці OPH перед тестом. Не покладатися на водійське посвідчення.
- Телефони, словники, власні пристрої і сторонні підказки під час екзамену заборонені відповідно до правил центру.
- Подати запит на **special arrangements**, якщо вони необхідні, у визначеному порядку завчасно.
- Сертифікат зазвичай приблизно через **2 місяці**. Доступний цифровий сертифікат за умов OPH (реєстрація з henkilötunnus + активні Suomi.fi Messages тощо).
- Оцінка за кожний модуль окрема; можливе оскарження/перегляд оцінювання за процедурою OPH. Перед оскарженням актуалізувати строки та тариф.

**Першоджерела:** [OPH — before test](https://www.oph.fi/en/education-and-qualifications/yki-test), [OPH — after test](https://www.oph.fi/en/education-and-qualifications/after-yki-test).

## Громадянство: окрема зміна з 2027

Новий **citizenship/civic knowledge test ≠ YKI**. Migri повідомляє, що нова вимога знань суспільства стосується заяв на громадянство, **поданих з 01.03.2027**, переважно для віку **18–64** (можливі винятки та альтернативні способи підтвердження). Заяви, подані до цієї дати, розглядаються за правилами відповідного періоду. Матеріали нового тесту мають бути опубліковані на межі 2026/2027. Навіть YKI 3+ сам по собі **не замінює** громадянський тест.

**Першоджерела:** [Migri — amendments](https://migri.fi/amendments-to-the-citizenship-act-2027), [Migri — новини 09.10.2026](https://migri.fi/en/-/up-to-date-information-on-amendments-to-citizenship-act-learning-material-for-citizenship-test-to-be-published-at-turn-of-the-year?languageId=en_US).

> Поради щодо громадянства тут — лише контекст мовної підготовки; це **не** юридичний висновок щодо конкретної заяви.
