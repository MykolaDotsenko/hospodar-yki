Use-case record template: `UC-###`, actor/persona (adult Ukrainian-speaking A2.2→B1+), trigger/goal, preconditions, main journey, alternate/error/offline paths, content and media dependencies, privacy/accessibility needs, acceptance test IDs, implementation status and measured evidence.

**High-priority scenarios:** learn a chunk with first attempt/repair/transfer; listen with subtitle fallback; speak when mic denied; resume draft after browser crash; device offline without 3GB first Web download; quiz answers never leak before submit; no graded B1 label for unreviewed speaking/writing; Android pack missing/low disk/upgrade. These are test **scenarios**, not claims that all flows currently run.
