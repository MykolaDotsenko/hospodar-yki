# Gameplay research — learning-first 2D city/NPC quests

**[Q-01…Q-04 language-first NPC quest design](gameplay-learning-loops-v1.md)** — future Phaser implementation, not shipped gameplay.

**Current status: design TARGET, not a Phaser game.** Sources: [game/Android ADR](../../docs/23-android-offline-game-and-3gb-media-architecture.md), [interactive visual research](../ux/interactive-visual-learning-v1.json), [modes](../user-cases/product-session-modes-v1.json), [learning methods](../pedagogy/learning-methods-v1.json).

Design each proposed loop as: everyday situation → Finnish comprehension/production → independent first attempt → contextual feedback/repair → new transfer situation. Distinguish **fun/retention hypotheses** from measured language improvement.

Future research records must include mechanic/NPC quest ID, persona, scenario, core learning behavior, no-hint EXAM exclusion, cognitive load concern, accessibility/reduced-motion fallback, technical cost, benchmark (FPS/memory) and user test plan. **Game scores never become an official YKI proficiency grade**. Browser and Android feature parity remains a release gate.

**Comparative gate:** see [research program](../RESEARCH-PROGRAM.md) and [UX-L05](../ux/learning-impact-evaluation-protocol.md). Each game scene must be compared with an equivalent plain-language task at matched practice exposure, including delayed *unseen* Finnish transfer; clicks, time-on-app, XP and retention alone do not prove learning. A 2025 [mobile language games meta-analysis](https://doi.org/10.1080/09588221.2025.2528786) reports positive pooled effects but weaker clarity for non-English and several skills, so Finnish YKI improvement is still an **unproven local hypothesis**.
