# Licensing and third-party material

**There is currently no repository-wide public software LICENSE grant.** Public access to the source code does not by itself grant permission to reuse, modify, or redistribute it. The maintainer must choose and approve a software license before adding a canonical `LICENSE`.

**Never assume one license covers this entire educational repository.** The project contains:
- Original software, specifications, brand identity, and project-authored exercises: rights/licensing require the maintainer's explicit decision.
- External PDF books, corpora, dictionaries, voice recordings, WebM and individual text excerpts: each file is governed by its **own source license, creator attribution and conditions**. Some sources are research-only or link-only.
- YouTube links, official YKI examples and publishers: URL discovery does not grant permission to download, make derivatives, distribute offline or import audio into training data.

Before publishing a Web release or Android PAD pack, verify the **specific asset**'s provenance, attribution, license compatibility and redistribution scope (including commercial use and derivative limitations). If unclear, ship a link rather than a copy. See [content guide](docs/guides/CONTENT-AUTHORING.md), [source verification](sources/learning/06-sources-and-verification.md), [media owner README](assets/README.md) and [security policy](docs/SECURITY.md).

When a maintainer chooses a code license, put it in `LICENSE` and add per-media notices/REUSE attribution where needed. Do **not** silently relicense third-party content.
