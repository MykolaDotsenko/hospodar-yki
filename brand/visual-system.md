# Hospodar YKI — authentic visual system v0.1

## Концепція: «Відчинені двері до розмови»

Замість шаблону «робот + градієнт + floating cards» — упізнаваний **поріг будинку**, який стає формою відкритої мовленнєвої репліки. Простий асиметричний знак символізує момент, коли учень **наважується говорити**.

**Фінський контекст:** логіка, спокійний інтерфейс, повітря, практичні фактури.  
**Український слід:** м'який теплий золотистий акцент, невелика ритмічна реміснича геометрія, не орнаменти «на всю площу» й не прапорна декоративність.

## Типографіка й композиція

- **Система:** humanist sans із доброю читабельністю української та фінської (ä, ö, й, ї, є, ґ). Початковий fallback: system-ui / Segoe UI / Arial; не додавати неочевидні ліцензії шрифтів до git.
- **Навчальний текст:** велика x-height, мін. 16px текст; просте кириличне/латинське змішування; не використовувати all caps для довгих завдань.
- **Ритм:** крок відступів 4/8/12/16/24/32 px, одна активна навчальна дія на екран; змістовні індикатори навички «Puhuminen», «Kirjoittaminen».
- **Сітка:** mobile-first, довгі фінські слова не обрізати; доступний інтерфейс для телефонів, планшетів і комп'ютерів.
- **Ілюстрації:** прості ліноритоподібні фрагменти міського життя (автобус, бібліотека, житло) зі стриманою нерегулярністю; уникати стокових щасливих персонажів біля гігантської мікрофонної іконки.
- **Анімація:** не більше 150–250ms для дрібних UI transitions, нульова/скорочена анімація за prefers-reduced-motion, без несподіваного аудіо.

## Логотип — робочий концепт

[Знак](logo/hospodar-yki-mark.svg) · [Wordmark / README lockup](logo/hospodar-yki-lockup.svg)

Це **векторні прототипи, а не остаточний товарний знак**. SVG має бути чітким у 24–32px, монохромному варіанті, на темній і світлій темах. Перед фіналізацією потрібні тест на впізнаваність, візуальна правка, PRH/EUIPO clearance. Не вбудовувати в знак точну копію фінського прапора, державну печатку чи «офіційний» штамп.

## Anti-AI-sameness правила для команди

- **Ні:** фіолетово-блакитним градієнтам за замовчуванням, глянцевим кулькам, псевдо-3D роботу, довільному glassmorphism, десятьом круглим dashboard-карткам без пріоритетів.
- **Так:** локальні побутові сценарії, сильна типографія, мікроілюстрації із функцією, обмежена палітра й асиметрія як характер.
- **Ні:** різким звуковим нагородам, беззмістовним streak, shame copy, декоративній «українськості» на кожному екрані.
- **Так:** кнопці «Повтори фінською», видимому прогресу за навичкою, поясненню «чому», самовиправленню без показу зразка.
- **Ні:** claims «B1 гарантовано» та штучним рейтингам як оздобленню.
- **Так:** поясненню невпевненості AI-оцінювання.

## Невеликі приклади екранів

**Home:** «Сьогодні — домовитися про новий час» → одна картка 15 хв, одна кнопка «Почати місію».  
**Speaking:** живий запит фінською, запис відповіді, керований таймер, потім «Що вдалося / Спробуй інакше».  
**Feedback:** 1 сильна сторона, 2 пріоритетні помилки, спроба самокорекції → схожа нова ситуація.  
**Progress:** робочий рівень і чотири навички; без імітації офіційних оцінок YKI.

Версія v0.1: поки лише концепт; візуальні рішення мають пройти тестування на реальних учнях.
