# Learning content

The real exercises live in [exercises/b1/](exercises/b1/) by lesson type and topic; [exercises/video/](exercises/video/) contains learning questions for externally sourced, separately licensed videos. See [exercises README](exercises/README.md) and [content authoring rules](CONTRIBUTING.md).

Keep Finnish prompts, explanations, response rules and content identities in the lesson files. Store audio and video binaries only in [assets](../assets/README.md). In LEARN, independent answers, repair and transfer are distinct; EXAM cannot reveal hints/keys before submission. New content needs S2 review and explicit rights/source information.
