# Правила внесення реальних YKI B1 матеріалів

Мета репозиторію — **content-first**: інструменти майбутнього застосунку мають читати вправи, ключі, пояснення, навчальні chunks і ліцензоване аудіо, а не агрегувати лише посилання.

**Додавати:** самостійно створені комунікативні ситуації, тематичні тексти B1, питання й перевірені відповіді, оригінальні аудіосценарії, справжнє аудіо з правами використання, якісні пояснення, приклади, фідбек, адаптивні педагогічні метадані.

**Не копіювати без дозволу:** сторінки платних книжок, ключі з захищених курсів, сторонні MP3 зі спеціальними умовами, повні тексти офіційних YKI зразків, скриншоти курсів.

## Контроль на кожну одиницю

- [ ] Є стабільний ID, рівень, тема і навчальна мета.
- [ ] Текст фінською природний і потрібного рівня, перевірений мовним редактором.
- [ ] Питання самодостатні, ключ точно правильний і нема другого правильного варіанта.
- [ ] Є пояснення **чому** відповідь правильна.
- [ ] Завдання не видається за справжній тест YKI.
- [ ] Аудіо існує у git **або** чесно позначено як `script_only`.
- [ ] До аудіо зазначено джерело, автора та ліцензію; synthetic audio позначено як synthetic.
- [ ] Цей контент перевірено машинним валідатором і людиною, якщо використовується для оцінювання.
- [ ] Приватні навчальні дані користувачів НЕ внесені до публічного репозиторію.

Висновки науки й педагогічні методи розміщувати в `research/pedagogy/`, поточні навчальні матеріали — у `learning/exercises/`, словники — в `knowledge/dictionaries/`, медіа — в `assets/`. Мета контенту — розвивати **здатність самостійно виконувати нові завдання**, а не вивчити відповіді.
