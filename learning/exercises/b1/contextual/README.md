**Без удаваної готовності:** короткі тексти не замінюють повні 2–3-хвилинні B1 записи; усі діалоги — script-only (НЕ слухова діагностика); приклади original draft, **S2 teacher review pending**. Немає тверджень про офіційну калібровку YKI.

Навчальний UX: (1) спроба без моделі → (2) змістова оцінка → (3) самовиправлення → (4) показ обґрунтування у джерелі → (5) схожа НОВА задача через затримку. Якщо слово учень уже впевнено використовує, **не** вносити його до особистого SRS лише тому, що воно є в каталозі.

Права: локальні авторські тексти/речення позначені `project_original`; сторонній частотний словник атрибутовано окремо, див. [frequency/README.md](../lexicon/frequency/README.md). Перелік інших ресурсів і дозволених сценаріїв: [docs/09](../../../docs/09-yki-content-materials-2026-10.md).
