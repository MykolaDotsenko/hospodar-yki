## Протокол

1. Новий стимул без підказки — спроба відповіді.
2. Зворотний зв'язок: спершу комунікативна мета, потім 1–3 критичні помилки.
3. Самовиправлення; лише після цього показати модель.
4. Після затримки — нова ситуація з тією ж функцією; не повторювати завчену.
5. `open` answers оцінювати за змістом; `single_choice` й `true_false` — за ключем і доказом із тексту.

**Тренувальні оцінки не є офіційним YKI 3/4.** Зразки відповідей не були оцінені YKI-екзаменаторами.

Ці вправи написані оригінально й не скопійовані з відкритих чи платних джерел. Перелік досліджених незалежних ресурсів — [source registry](independent-sources.json). Ресурси VIERKO CC BY-SA потребують окремої атрибуції при копіюванні їхнього оригінального змісту.
