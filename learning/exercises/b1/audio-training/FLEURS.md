# 🇫🇮 FLEURS human Finnish listening samples

**Це допоміжне джерело справжніх людських голосів, не офіційне YKI.**

Джерело: [Google FLEURS Finnish fi_fi](https://huggingface.co/datasets/google/fleurs). Дозвіл: **Creative Commons Attribution 4.0**. Атрибуція: Conneau et al. (2022), *FLEURS: Few-shot Learning Evaluation of Universal Representations of Speech*. https://arxiv.org/abs/2205.12446.

Скрипт [import_fleurs_human_audio.py](../../../../scripts/import_fleurs_human_audio.py) завантажує вибірку з validation-набору, вичитаний носіями/дикторами текст корпусу, перетворює вихідне аудіо в OGG Vorbis (це похідний технічний формат), зберігає `sha256`, час, цитування й очікуваний текст у `fleurs-fi.json` (файл ще не імпортований).

**Увага:** це переважно *читане* мовлення, а не живі побутові діалоги. Можливі довгі академічні речення, не відкалібровані за B1. Їх можна тренувати як диктант і короткий переказ, але НЕ використовувати як тест для твердження «учень склав YKI 3».

**Фактичний стан 21.10.2026: 0 файлів імпортовано.** Два незалежні запуски GitHub Actions підтвердили недоступність preview API FLEURS: HTTP **500** на /rows і **501** на /first-rows. Не зараховувати FLEURS до збереженої колекції й не підміняти людським голосом TTS. Імпорт збережено як **ручний workflow** на випадок відновлення зовнішнього сервісу.

**Стан завантаження перевіряти фактично:** ні `fleurs-fi.json` (файл ще не імпортований), ні `assets/audio/human/fleurs-fi/` (папка ще не створена) не вважати наявними, доки не підтверджено завершений workflow та дерево GitHub.

**Практика:** перше прослуховування без транскрипту → відтворити зміст → повторне прослуховування → короткий диктант → самокорекція й показ вихідного транскрипту.
