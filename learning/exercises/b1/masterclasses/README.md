# 🎓 Hospodar YKI — 12 власних B1 майстер-класів

**Практичний навчальний контент, а не каталог посилань.** [Відкрити всі уроки у структурованому JSON](lessons.json).

У пакеті 12 занять по 25 хв, 24 питання з ключами та доказами, 12 завдань самовиправлення, 12 власних усних/письмових відповідей зі зразками та 12 нових завдань для самостійного перенесення (**60 активностей**).

## Принцип

Самостійна перша спроба → коротке пояснення → 2 питання → виправлення невдалої відповіді → власна відповідь → transfer без готового рішення.

Три модулі пов'язані з уже наявними локальними аудіоуроками. У кожному явно сказано, що навчальний демотекст **не є точною транскрипцією запису**. Питання демотексту не використовувати для оцінки аудіювання: у реальному аудіоплеєрі брати ключі його власного маніфесту.

**Підготовка для YKI keskitaso** — не офіційні завдання і не екзаменаційна калібровка. Мовна перевірка кваліфікованим S2-викладачем поки не виконана.
