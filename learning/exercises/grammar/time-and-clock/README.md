# Kello ja aika — години, розклад, часові вирази (A1.3–A2.1)

**Окремо від граматичних часів (aikamuodot)**: [вправи з годинами](lessons.json), зустрічами та розкладом. Розвиваємо `Kello on puoli neljä` (15:30), `varttia yli` і `varttia vaille`.

**У застосунку:** зрозумілий візуальний годинник + доступне текстове представлення, самостійна відповідь до підказки, власна фраза про час зустрічі. Можливі предметні ілюстрації в [assets/images/illustrations](../../../../assets/images/illustrations/README.md).

**Статус:** оригінальний чернетковий контент, review викладача очікується. Джерело відео [University of Turku — Kello ja aika](https://www.youtube.com/watch?v=M_2tFoljI70) збережено лише як YouTube-посилання.
