# Aikamuodot — граматичні часи фінської (A1.3–B2.1)

**Навчальний розділ:** [4 часи і 9 оригінальних вправ](lessons.json). **Драфт:** потрібна перевірка викладача фінської перед оцінюванням чи масовим публічним випуском.

| Рівень | Час | Приклад |
| --- | --- | --- |
| A1.3–A2.1 | **Preesens** — теперішнє / майбутнє з `huomenna` | `Opiskelen suomea.` / `Huomenna menen töihin.` |
| A2.1–A2.2 | **Imperfekti** — простий минулий | `Eilen opiskelin.` |
| A2.2–B1.1 | **Perfekti** — минуле з актуальним зв’язком | `Olen opiskellut suomea.` |
| B1.2–B2.1 | **Pluskvamperfekti** — передминулий | `Olin lähtenyt ennen kokousta.` |

У фінській **немає окремого обов'язкового граматичного майбутнього часу**: preesens із часовим маркером часто виражає майбутню дію. Не плутати часи (`aikamuodot`) зі способами дієслова (`imperatiivi`, `konditionaali`). Всі приклади власні, не скопійовані зі сторонніх підручників.

**Рекомендований UX:** спочатку незалежне заповнення/вибір → негайне пояснення різниці → власне речення → інший невідомий приклад через 7/14 днів. Для відкритого письма — статус `ungraded`, не офіційний B1.

**Джерела для перевірки:** [Kielitoimiston ohjepankki](https://kielitoimistonohjepankki.fi/ohje/aikamuotoja-aloita-tasta/), [Aalto Finnish Online Grammar](https://openlearning.aalto.fi/course/view.php?id=158), [OPH](https://www.oph.fi/fi/koulutus-ja-tutkinnot/kielitiedon-opettamisesta).
