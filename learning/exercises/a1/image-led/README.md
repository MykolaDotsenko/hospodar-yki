# A1.3–B1.1 image-led Finnish situation missions

[Eight original practical missions](lessons.json): supermarket/shop, bus stop, housing and Turku market. These are **LEARN draft tasks**, awaiting **teacher review**. All eight local photos **are now verified binaries** in [available.json](../../../../assets/images/pictures/available.json), but the lessons are still editorial drafts, not released/official graded exam items.

A learner first independently describes the picture in Finnish. Next, the app may show an example sentence, and then a new scenario requires actual production. No official YKI grade is computed for open speaking/writing responses. Captions must not silently reveal a task's answer. For accessibility, use meaningful bilingual alt with an alternative text-only prompt.

Attribution to source authors, CC BY-SA 4.0 license and resized-thumbnail derivative notices must accompany photos in all Web/Android displays. [Picture source and rights](../../../../assets/images/pictures/SOURCES-AND-LICENSES.md).
