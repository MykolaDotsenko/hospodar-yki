# 🇫🇮 Hospodar YKI — повна траєкторія A1.3 → B2.1

**Продуктовий контракт TARGET з 2026-10-23:** курс починається з **A1.3** і охоплює **A1.3 → A2.1 → A2.2 → B1.1 → B1.2 → B2.1**. На відміну від попереднього фокуса на A2.2→B1+, це програма для ширшого діапазону початково-середнього рівня. [Єдиний машинний план](levels-a1.3-b2.1.json).

- Вхід: навчальний маршрут A1.3 за замовчуванням, діагностика може визначити інший стартовий рівень; не примушувати досвідчених учнів заново проходити початок.
- Два режими **LEARN** і **EXAM** із чотирма навичками. Підготовка до YKI keskitaso концентрується на B1/B2, але **A1.3–A2.2 — педагогічне підґрунтя**, не фальшиве відтворення офіційного іспиту.
- Для кожного рівня — діалоги, граматика, аудіо, інтерактивні запитання, ілюстрації/зображення та відкладені перевірки у новому контексті.
- Частина A1.3/A2/B2.1 **ще не реалізована в Web MVP**; поточні `learning/exercises/b1/` й аудіо орієнтовані переважно на B1. Не називати каталог готовим курсом.
- Невелика офіційна CEFR шкала A1–C2 має локальні фінські підрівні; `A1.3`, `B1.2`, `B2.1` — **планові підрівні курсу**, не сертифіковані результати учня.
- Граматичні часи — [tenses](../exercises/grammar/tenses/README.md), години й календарний час — [time-and-clock](../exercises/grammar/time-and-clock/README.md).
- Навчальні ілюстрації — [assets/images/illustrations](../../assets/images/illustrations/README.md), реальні картинки — [assets/images/pictures](../../assets/images/pictures/README.md). Завдання залишаються у `learning/`, а файли — в `assets/`.
- Майбутній імпорт контенту: стабільні IDs, CEFR-мітка, права, human Finnish review; синхронізувати індекси, не дублювати каталоги.
