# 📅 Навчальні плани фінської мови

Тут зберігаються **навчальні послідовності і плани**, а не аудіофайли чи джерела знань. Кожен план може посилатися на вправи з [learning/exercises](../exercises/README.md) та звук із [assets/audio](../../assets/audio/README.md).

- [listening-4-weeks.json](listening-4-weeks.json) — 28 днів приблизно по 20 хв: загальне розуміння, деталі, самокорекція, новий контекст.
- [listening-lesson-plan.json](listening-lesson-plan.json) — методичні завдання для прослуховування, короткого переказу, реакцій і чисел.

Це **авторські тренувальні програми Hospodar YKI**, а не розклад чи офіційні завдання OPH. Планам потрібно зберігати сталі ID, коректні посилання на існуючі вправи/медіа, статус методичної й мовної перевірки та пояснення, як оцінюється прогрес.

**Правило:** нові плани додаємо сюди, а не до `assets/`. Не створювати окремий глобальний реєстр навчальних планів.
