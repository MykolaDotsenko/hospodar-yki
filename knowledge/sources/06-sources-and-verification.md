# 06 — Джерела, звірка тверджень та обслуговування документації

> **Стан:** 2026-10-21. Мета — щоб у документацію і код додатка не потрапляли «підтвердження» із некоректних переказів або застарілих курсів.

## Ієрархія достовірності

1. **A / OFFICIAL:** чинні OPH, Migri, University of Jyväskylä для власних демо.
2. **B / RESEARCH:** peer-reviewed статті, метааналізи, DOI/академічні сторінки; читати принаймні анотацію, дизайн і обмеження.
3. **C / PROVIDER:** видавництво, автор курсу, офіційний сайт продукту; це підтверджує **обіцяну структуру/ціну**, але не незалежну ефективність.
4. **D / INTERPRETATION:** власні методичні пропозиції, рейтинги 0–100 та навчальні приклади. **Не представляти** як офіційний факт.

## Важливі застереження з аудиту цього діалогу

| Твердження з попередніх обговорень | Перевірений статус |
|---|---|
| «YKIä kohti — найкращий підручник 96/100» | **Оціночна рекомендація**, не незалежний факт / не «бестселер» |
| «Я прочитав усі книги і майстер-класи» | **Ні** — підтверджено видавничі описи, відкриті фрагменти і програми; доступу до всіх платних сторінок немає |
| «Точно такі самі task timers у цифровому YKI» | **Ні** — існують історичні демо; цифровий UI/таймінг підлягає актуалізації |
| «Реєстрація 8.03.2027 10:00» | **Так** за офіційним OPH-календарем 2026-10-21; ще раз перевірити перед датою |
| «13.02.2027 повний keskitaso» | **Так** за OPH, формат цифровий |
| «Квітневий тест 10.04.2027 — усі частини» | **Так**, OPH |

## Політика внесення змін до документації

- У Markdown ставити реальні прямі URL на першоджерела, не посилатися на внутрішні номери цитат чату.
- Якщо немає доступу до повного тексту — писати «перевірено абстракт/фрагмент».
- Зміни у вимогах/цінах з датою фіксувати в відповідному файлі, а тут оновлювати код/URL лише за потреби.
- Жодних вигаданих completion %, YKI scores чи оцінок користувача.
- Репозиторій **публічний**: не зберігати імен, приватних діалогів, аудіозаписів, особистих відповідей або чутливих даних без окремої перевірки приватності.
