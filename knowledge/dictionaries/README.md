# Фінські словники, chunks і керування

Словники фізично розміщені тут, у `b1/`. Це **не реєстр посилань**, а реальні дані:

- [Контекстні chunks](b1/contextual-chunks-v1.json) — фінські конструкції та приклади.
- [Rektio](b1/rektio-v1.json) — керування дієслів/відмінків.
- [Частотний словник](b1/frequency/README.md) — файл TSV і атрибуція джерела.

Практичні cloze-вправи залишаються окремо в [learning/exercises/b1/grammar](../../learning/exercises/b1/grammar/). Особистий словник незнайомих слів і SRS-стан користувача — приватні дані застосунку, а не Git.
