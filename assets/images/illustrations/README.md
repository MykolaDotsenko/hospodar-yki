# Навчальні ілюстрації / Illustrations

**Папка створена для реальних графічних навчальних матеріалів** на рівні **A1.3–B2.1**: схеми часів (`preesens → imperfekti → perfekti → pluskvamperfekti`), візуальні годинники, місця в місті, дорожні знаки, лексичні карти, ситуативні панелі, інфографіка. У папці вже є **5 справжніх навчальних SVG** (4 годинники та 1 схема граматичних часів). [Машинна бібліотека з точними FI/UK описами](library.json). Педагогічне рецензування прикладів ще очікується.

- Сюди: оригінальні або законно ліцензовані SVG/WebP/PNG/AVIF, оптимізовані для Web/Android, семантичні підпапки за темою при фактичній появі файлів.
- Кожна змістовна ілюстрація потребує стабільного asset ID, рівня/теми, `alt_fi`, `alt_uk`, автора, ліцензії, джерела й підтвердження прав. Декоративні повинні явно мати порожній alt.
- Уникаємо когнітивного перевантаження, конфліктів кольору із задачею, фото/облич без згоди й зображень із прихованими правильними відповідями для EXAM.
- Текстовий еквівалент доступний навіть без зображення; Web/Android споживають **те саме медіа**, не створюють паралельні каталоги.
- При додаванні фактичних файлів оновити відповідний навчальний lesson/media manifest та пройти технічний/ліцензійний QA.
