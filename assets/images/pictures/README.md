# Картинки й фотографії / Pictures

**Папка для реалістичних предметних зображень** (не плутати з авторськими `illustrations/`): помешкання, супермаркет, лікар, робоче місце, документи, транспорт, погода, їжа, фінське повсякдення, світлини для усних/письмових описів **A1.3–B2.1**.

**Партія 1:** [4 перевірених за ліцензіями джерела](SOURCES-AND-LICENSES.md), [джерельні картки](sources.json) та [фізично доступні файли](available.json). Кандидати не рахуються як локальні JPG до успішного імпорту й SHA-256. Перед додаванням:
- Перевірити відповідність темі/рівню та використання в реальній вправі, а не для кількості.
- Використовувати власні або явно ліцензовані матеріали (автор, сторінка джерела, дозволена похідна обробка, attribution, обличчя/особисті дані).
- Створити доступні `alt_fi`/`alt_uk`, масштабовані Web/Android формати, контроль розміру й чіткий статус педагогічного рецензування.
- Розміщувати відповіді на завдання окремо; EXAM не повинен показувати підказки на картинці.

[Програма A1.3–B2.1](../../../learning/curriculum/README.md) · [ілюстрації](../illustrations/README.md).


Чотири реалістичні ситуації: міський ринок, супермаркет, житловий будинок, автобусна зупинка. Під них створено [4 оригінальні мініуроки](../../../learning/exercises/a1/image-led/README.md). Фізичний імпортер — [scripts/import_licensed_pictures.py](../../../scripts/import_licensed_pictures.py).
